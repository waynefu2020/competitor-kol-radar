# 坑清单（实战踩过的）

每一条都是真实发生过、会让结论出错的问题。抽查和解读数字前过一遍。

## 数据噪音

- **同名噪音**：品牌名撞上人名、地名、常用词。例：搜 "Plaud" 混进大量波多黎各新闻（政治人物 Félix Plaud），西语 "aplaudir" 也会命中。→ 写 `noise_regex`，并用产品词组合搜索。
- **官方号和区域官方号**：如 plaud_vn、@plaudai_india、@flowerknows.us。→ `official_regex` 剔除，否则会把品牌自播算成红人内容。
- **仿冒/转售号**：用户名里带品牌名的小号（如 flowe_rknowsmakeup 挂 Shopee 链接卖货）。→ 用户名含品牌名的一律剔除。
- **竞品赞助的对比视频**："Flowtica vs Plaud" 这类视频带折扣码和 sponsored，但出钱的是竞品。→ 看赞助方是谁，剔除或单列。
- **第三方工具号**：第三方 App 借品牌话题推自己（如 Nomily 接 Plaud）。→ 剔除。

## 分类误判

- **YouTube 简介里的其他品牌折扣码**：博主简介常挂十几个品牌的码。→ 只看标题和简介里提到本品牌的那几行（normalize.py 已实现）。
- **美妆的 "PR" 不等于付费**：#PR / PR package 在美妆圈通常是寄样。日本 #PR 通常是有偿或提供，需结合文案。→ 寄样单独一类，不并入付费。
- **TikTok `branded_content_type` 含义是推断的**：样本里 7 / 13 基本对应 TikTok Shop 挂车；1 / 4 / 17 / 18 对应商业内容披露，文案里寄样、折扣码、#AD 都有。TikHub 没有官方说明，报告里要注明。
- **零售商赞助**：YesStyle haul 带 YesStyle 码，出钱的是零售商不是品牌。→ 归联盟，渠道记零售商。

## 指标陷阱

- **IG 播放量大量缺失**：话题接口多数帖子不带播放量，只有部分 Reels 有。→ IG 用点赞做互动指标，播放中位数注明样本量。
- **IG v3 话题接口没有发布时间**：无法筛时间窗。→ 用 v2（`/api/v1/instagram/v2/fetch_hashtag_posts`）。
- **TikTok 关键词搜索不能按时间筛**：`publish_time` 参数传了会返回空。→ 全量抓回后按 `create_time` 过滤。
- **小红书按"最热"排序会返回半年前的旧帖**：→ "最热"+"最新"两种排序都抓，再按时间过滤。
- **Similarweb 直接访问偏高**：会混入 Web 端产品登录用户和老用户回访（Plaud 68%）。→ 不能直接当品牌认知；联盟点击经 Impact 跳转后常被记成引荐或直接访问，所以联盟占比会被低估。
- **社交流量低 ≠ 红人没用**：红人转化常被折扣码、亚马逊、线下、品牌词搜索承接。

## 工程

- **TikHub 用 Python urllib 直连会 403**：要带 User-Agent（tikhub.py 已处理）。
- **余额不足时接口会中途失败**：先 `--dry-run` 看预估和余额。
- **Key 安全**：Key 只放环境变量或 `~/.config/tikhub/key`，不要写进 skill、脚本、报告或回复。
