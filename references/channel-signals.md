# 渠道信号怎么读

## 从内容里能看到的

| 信号 | 指向的渠道 | 说明 |
|---|---|---|
| TikTok Shop 锚点、#tiktokshop、orange cart、keranjang、carrito | TikTok Shop | 分佣带货，播放通常偏低但量大 |
| 品牌官网链接 + 个人折扣码（code XXX 10% off） | 官网 DTC + 联盟计划 | 码的折扣力度能看出品牌给的让利（Plaud 10%，花知晓 5%） |
| `*.sjv.io`、`?ref=`、impact 链接 | Impact 等联盟平台 | 品牌在开放联盟招募 |
| amzn.to / geni.us / Amazon storefront | 亚马逊 | 常见于 YouTube 测评长尾 |
| YesStyle / Stylevana / Shopee / Lazada / SHEIN | 第三方电商 | 可能是零售商赞助，不一定是品牌出钱 |
| Ulta / Best Buy / Target / 药妆店 / store locator | 线下零售 | 结合新闻确认门店数和上线时间 |
| pop-up、快闪、打卡、具体商圈话题（#seongsu） | 品牌快闪 | 线下体验为社媒提供拍摄场景 |
| 评论区关键词领链接（"comment PLAUD for the link"） | 私信自动回复导流 | 低成本转化技巧 |

## 需要外部补的

- **官网流量结构**（Similarweb）：自然搜索、付费搜索、直接、社交、联盟、邮件、AI 聊天机器人。社交占比高说明社媒导流直接有效；直接访问高要考虑产品登录用户干扰。
- **零售与电商入驻**：搜新闻稿（PRNewswire、BusinessWire）、行业媒体（Beauty Independent、Jing Daily、36氪、界面）。
- **规模**：营收、出货量、估值、融资；国内报道和海外报道口径常不一致，两个都写。

## 写渠道章节的结构

1. 一句话判断：核心渠道是什么，正在加码哪个。
2. 内容指向的渠道分布（条形图）。
3. 官网流量来源（有数据才放）。
4. 渠道表：渠道 / 地位（核心、主要、补充）/ 证据。
5. 规模参考：口径不一的数字全部列出并标来源。
